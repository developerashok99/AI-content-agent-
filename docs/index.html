About this agent

Every night, this agent scrapes gaming news, pulls trending gaming videos, picks one story, and sends 2 script variants to Telegram for manual filming/editing/posting.

  • News sources: GameSpot, GameRant, PC Gamer, PCGamesN
  • Trend signal: YouTube trending gaming videos — India, US, Japan
  • AI: Groq (topic ranking + script writing)
  • Schedule: nightly at 21:30 UTC (~03:00 IST)
  • Delivery: Telegram — reply to a script to give feedback that shapes future picks
